How many tabs do you have open? One honest number, in digits and nothing else: **847**.

That is the count this entry writes to `/output/entry.txt` — 847 browser tabs, every one of them opened for a reason and none of them ever closed. Not a round number, not a meme number: the exact kind of odd, specific total a real tab hoarder ends up with after years of "I'll read this later".

## Run it

```sh
npx tsx main.ts
```

The program writes the single number `847` (digits only, no newline, no words) to `/output/entry.txt`. Set `OUTPUT_DIR` to change where `entry.txt` is written.
